# Practical 04: Python Password Strength Checker

Author: Samuel Njenga

## Objective
Build a Python tool that evaluates basic password
strength using length and character requirements.

## Technology
- Python 3
- Regular expressions
- Termux on Android

## Features
- Checks password length.
- Checks uppercase and lowercase letters.
- Checks numbers.
- Checks special characters.
- Produces a strength score out of 5.
- Provides improvement recommendations.

## Test Results

Test 1: rariem12
Result: WEAK
Score: 2/5

Test 2: CyberSafe@2026
Result: STRONG
Score: 5/5

## Security Lessons
- Longer passwords are generally preferable.
- Passwords should use varied character types.
- Avoid reusing passwords across accounts.
- Never expose real passwords in logs or screenshots.

## Limitations
This is an educational checker. It does not
check breached passwords, common password lists,
or resistance to modern guessing attacks.

## Conclusion
The project demonstrates basic Python automation
applied to password security awareness.
